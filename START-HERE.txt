LinguaPath — как запустить на своём компьютере

Понадобится только Node.js. MongoDB, Docker и другие программы ставить не нужно:
база данных запустится сама, а курсы и демо-аккаунты загрузятся при первом запуске.

1. Установите Node.js с сайта https://nodejs.org — кнопка «LTS», установка со всеми
   настройками по умолчанию.
2. Распакуйте архив в любую папку, например на рабочий стол.
3. Запустите:
   - Windows: двойной клик по start-windows.bat
     (если Windows покажет синее окно «Система защитила ваш компьютер» —
     «Подробнее» → «Выполнить в любом случае»);
   - macOS: правый клик по start-mac.command → «Открыть» → «Открыть».
4. Первый запуск занимает 3–10 минут: скачиваются библиотеки и база данных.
   Когда в окне появится «LinguaPath запущен», сайт сам откроется в браузере.
   Если не открылся — перейдите по адресу http://localhost:8080

Вход:
   Учащийся с историей занятий:  demo@linguapath.local / LinguaDemo2026
   Администратор:               admin@linguapath.local / LinguaAdmin2026
   Можно зарегистрировать и новый аккаунт.

Окно с текстом не закрывайте, пока пользуетесь сайтом: закрытие окна останавливает сайт.
Следующие запуски — тем же файлом, они занимают несколько секунд.
Все данные хранятся в папке demo-data; чтобы начать с чистого листа, удалите её.

Что посмотреть:
   - «Сегодня» — персональный план с объяснением каждой рекомендации;
   - «Путь» — уроки A1–B2, «Повторение» — карточки по интервальному повторению;
   - «Прогресс» — графики и журнал ошибок;
   - «Профиль» → «Оформление» — темы «Ночь», «День», «Бумага»
     (переключатель есть и внизу бокового меню);
   - вход администратора — панель управления курсами, словарём и тестами;
   - http://localhost:8080/api/docs — документация API (Swagger).

Озвучка и распознавание речи работают через браузер; лучше всего — в Google Chrome
или Microsoft Edge. Если для какого-то языка в системе нет голоса, сайт предложит
пропустить задание без штрафа.

Если что-то не запускается:
   - «Port 8080 is already in use» / «EADDRINUSE» — закройте другое окно с сайтом
     или перезагрузите компьютер;
   - ошибка при установке — проверьте интернет и запустите файл ещё раз;
   - Node.js должен быть версии 20 или новее (проверить: в терминале команда node -v).

В архиве также лежит docs/UXUI_LinguaPath.docx — документ с UX/UI-проектированием,
и docs/ — описание архитектуры, алгоритма рекомендаций и тестирования.
