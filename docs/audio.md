# Озвучка

Все слова, примеры, фразы теории, задания, контрольные тесты и задания входного теста озвучены заранее: **4569 записей**, 43 МБ на пять языков. Реплики второго собеседника в диалогах записаны другим голосом.

## Почему так, а не через облачный сервис

| Вариант | Казахский | Ключ и оплата | Работает у проверяющего без настройки | Итог |
|---|---|---|---|---|
| Web Speech API (голоса браузера) | Обычно нет голоса | Нет | Зависит от системы | Оставлен запасным вариантом |
| Microsoft Azure Speech | Есть (kk-KZ, два голоса) | Ключ, платно сверх бесплатного лимита | Нет: нужен ключ на сервере | Не выбран |
| ElevenLabs | Заявлен | Ключ, платно | Нет | Не выбран |
| Google Cloud Text-to-Speech | Не подтверждён | Ключ, платно | Нет | Не выбран |
| **Piper (нейросетевые VITS-модели, запуск через sherpa-onnx)** | **Да: голоса ISSAI, 6 дикторов** | **Нет** | **Да: записи уже лежат в проекте** | **Выбран** |

Записи генерируются один раз на компьютере разработчика. Сайт ничего не отправляет внешним сервисам: нет ключей, расходов и передачи данных учащихся третьим лицам, а звук одинаковый в любом браузере, в том числе без системных голосов.

## Как устроено

1. `npm run audio:phrases` (`tools/audio/collect.ts`) собирает из учебного контента все фразы на изучаемом языке, которые может проиграть интерфейс: слово и пример, примеры теории, текст задания на чтение и аудирование, правильный ответ на изучаемом языке, реплики диалогов с указанием собеседника.
2. `tools/audio/generate.py` синтезирует недостающие записи (MP3, 32 кбит/с, моно), выравнивает громкость, добавляет короткие паузы по краям и пишет `client/public/audio/<язык>/manifest.json`: фраза → файл. Имя файла — хеш голоса и текста, поэтому повторный запуск дописывает только новые фразы.
3. Клиент (`client/src/lib/speech.ts`) загружает манифест языка и играет в порядке приоритета: запись, загруженная администратором → подготовленная запись → синтез речи браузера.

Новые уроки, добавленные через админ-панель, сразу звучат голосом браузера. После повторного запуска двух команд выше у них появятся записи.

## Что видит учащийся

- Кнопка «Прослушать» у каждого слова, примера и реплики. Повторное нажатие в течение 4 секунд проигрывает фразу медленнее (0,7×) без искажения тона.
- Аудирование: автоматическое воспроизведение, кнопка «Медленнее». Задание работает и в браузере без голосов.
- Диалоги: «Прослушать диалог», после ответа — «Прослушать диалог целиком» с правильной репликой; собеседники звучат разными голосами.
- После ответа можно прослушать правильный вариант.
- На странице урока — «Прослушать все слова».
- Задание на произношение: «Слушайте и повторяйте» — запись своего голоса в браузере для сравнения с образцом. Работает в любом браузере с микрофоном, в том числе для казахского, который браузерное распознавание речи обычно не поддерживает. Запись никуда не отправляется.
- На главной странице у каждого языка можно услышать голос курса.

## Проверка качества

Каждая четвёртая запись голоса A (589 записей) распознана обратно моделью Whisper large-v3-turbo с указанием языка и сравнена с исходным текстом по доле ошибочных символов (CER). Повторы, в которые Whisper зацикливается на очень коротких записях, схлопываются.

| Язык | Фразы от 3 слов: медиана CER | Фразы: доля с CER ≤ 10% | Отдельные слова: доля с CER ≤ 10% |
|---|---|---|---|
| Английский | 0% | 82% | 67% |
| Турецкий | 0% | 91% | 38% |
| Немецкий | 0% | 95% | 65% |
| Испанский | 0% | 91% | 65% |
| Казахский | 24% | 11% | 26% |

Как читать результат:

- Для английского, немецкого, турецкого и испанского большинство фраз распознаётся слово в слово.
- Отдельные слова распознаются хуже из-за самого распознавателя: короткий звук без контекста, числа записываются цифрами («three» → «3»), похожие слова подменяются.
- Whisper заметно хуже распознаёт казахскую речь. В расшифровках пропадают именно казахские буквы (ү, ң, ө: «Біз кеше кино көрдік» → «Біз кешей кену крдіп»), поэтому высокий CER нельзя считать оценкой самого синтеза. Казахскую озвучку стоит прослушать носителю; это записано в ограничениях.

Полный отчёт: `tools/audio/.work/quality-report.json` (создаётся командой `generate.py --check --every 4`).

## Ограничения

- Синтезированная речь звучит ровнее живой: интонация вопросов и эмоции передаются слабее.
- Голос B для немецкого — модель низкого качества (16 кГц), других свободных женских немецких голосов среди моделей Piper нет.
- Казахская озвучка автоматически проверена только частично (см. выше).
