# Чек-лист выполнения технического задания

Отметка «✅» означает «реализовано и проверено»; «⚠️» — «реализовано с ограничением» (пояснение в строке).

## 2.1 Пользователи
- ✅ Регистрация, вход, выход, восстановление пароля (⚠️ без SMTP — ссылка в режиме разработки)
- ✅ Редактирование профиля, смена пароля, удаление аккаунта
- ✅ Выбор языка и начального уровня (входной тест или вручную)
- ✅ История обучения (`attempts`, `answerevents`, `reviewlogs`)
- ✅ Роли «пользователь» и «администратор»; защита данных и сессий

## 2.2 Языки
- ✅ Казахский, английский, турецкий, немецкий, испанский; уровни A1–B2
- ✅ Входное тестирование (адаптивное), просмотр уровней, продолжение с последнего места

## 2.3 Обучение
- ✅ Курсы → модули → уроки; организация по языку, уровню, теме
- ✅ Тематические словари с переводами и примерами
- ✅ Интерактивные карточки (режим «только карточки» в повторении)
- ✅ Грамматика и лексика: перевод, пропуски, выбор, порядок слов, сопоставление, диалоги
- ⚠️ Аудиосопровождение: Web Speech API или загруженные файлы; зависит от голосов браузера
- ✅ Повторение ранее изученного; сохранение результатов после каждого урока

## 2.4 Тестирование
- ✅ Входное, после уроков, итоговые тесты модулей
- ✅ Автоматическая проверка, проценты и баллы, история попыток, повторное прохождение
- ✅ Анализ ошибок по категориям; результаты используются в рекомендациях

## 2.5 Рекомендации
- ✅ Анализ результатов, ошибок, истории, регулярности, слов, динамики
- ✅ Следующие уроки, слабые темы, повторение слов, корректировка сложности, план, учёт прогресса
- ✅ Взвешенная модель на правилах с настраиваемыми весами; архитектура для замены моделью ML

## 2.6 Интервальное повторение
- ✅ История ответов, определение слов к повторению, дата следующего повторения, ежедневный список, учёт правильности (упрощённый SM-2)

## 2.7 Личный кабинет
- ✅ Языки и уровни, общий прогресс, пройденные уроки, результаты тестов, изученные слова
- ✅ История активности, графики динамики, рекомендации, план и задания для повторения

## 2.8 Администрирование
- ✅ Языки, курсы, уровни, модули, уроки, задания, тесты, слова, переводы, примеры
- ✅ Загрузка аудио и изображений; управление доступностью (публикация)
- ✅ Список пользователей, общая статистика, агрегированная успеваемость

## 3–4 Архитектура и API
- ✅ React + TypeScript + React Router + Axios + Chart.js; Node.js + Express + REST + JWT + bcrypt
- ✅ Валидация входных данных (zod), централизованная обработка ошибок
- ✅ MongoDB: коллекции, связи, индексы, проверки целостности на уровне приложения
- ⚠️ Dictionary API (Wiktionary): живой запрос не проверен из-за закрытой сети
- ✅ Web Speech API (озвучка, экспериментальное распознавание)
- ⚠️ Docker и docker-compose: конфигурация готова, сборка не проверена до конца (лимит Docker Hub)
- ✅ Swagger/OpenAPI

## 5 Нефункциональные требования
- ✅ Адаптивный интерфейс (проверено на 1440×900 и 390×844)
- ✅ Безопасность: хеширование, httpOnly-cookie, ротация токенов, CSRF, rate limiting, helmet
- ✅ Модульная структура; новые языки добавляются через админ-панель без изменения кода

## 6 Тестирование
- ✅ 121 автоматический тест (модульные, интеграционные, компонентные) — все проходят
- ✅ Сквозной сценарий в браузере (Playwright)
- ⚠️ Не выполнены: нагрузочное тестирование, кроссбраузерные проверки, автоматический аудит доступности
