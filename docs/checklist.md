- ✅ Взвешенная модель на правилах с настраиваемыми весами; архитектура для замены моделью ML
- ⚠️ Офлайн-оценка на синтетических профилях: движок обходит случайную и последовательную стратегии по покрытию слабых мест и минимальному умению на профилях со слабыми местами; у профиля без выраженных слабых мест случайная стратегия покрывает «самую слабую тему» чаще, а у двух профилей движок проходит меньше новых уроков (см. `evaluation-results.md`). ## 3–4 Архитектура и API
- ✅ React + TypeScript + React Router + Axios + Chart.js; Node.js + Express + REST + JWT + bcrypt (реализация `bcryptjs`)
- ✅ Валидация входных данных (zod), централизованная обработка ошибок
- ✅ MongoDB: коллекции, связи, индексы, проверки целостности на уровне приложения
- ⚠️ Dictionary API (Wiktionary): даёт определения на английском, а не переводы на русский; живой запрос не проверен из-за закрытой сети
- ✅ Web Speech API: озвучка; распознавание речи — экспериментально, при недоступности предлагается письменная замена задания
- ⚠️ Docker и docker-compose: состояние сборки указано в README
- ❌ Публикация в облаке: не выполнена, есть локальный запуск одной командой (`npm run demo`) и docker compose
- ⚠️ Swagger/OpenAPI: запросы описаны схемами zod; ответы описаны ссылкой на типы DTO, а не схемами

## 5 Нефункциональные требования
- ✅ Адаптивный интерфейс (проверено на 1280×860 и 390×844, сквозной тест на отсутствие горизонтальной прокрутки)
- ✅ Безопасность: хеширование, httpOnly-cookie, ротация токенов, CSRF, rate limiting, helmet; пароль администратора обязателен в docker compose
- ✅ Модульная структура; новые языки добавляются через админ-панель без изменения кода
- ✅ Контрастность WCAG AA во всех темах оформления

## 6 Тестирование
- ✅ 142 модульных и интеграционных теста и 3 сквозных теста Playwright — все проходят
- ✅ Нагрузочное тестирование: 1000 одновременно занимающихся учащихся на одном сервере с 4 ядрами — p95 42 мс, без ошибок; до 3000 — без ошибок, с ростом задержки (см. `load-testing.md`)
