Интеграционные тесты работают с настоящим MongoDB через `mongodb-memory-server`, у каждого файла своя база. В закрытой сети можно указать локальный бинарник через `MONGOMS_SYSTEM_BINARY=/path/to/mongod`.

Запуск:

```bash
npm test                          # все наборы
npm run test --workspace server   # только сервер
npm run test --workspace client   # только клиент
npm run typecheck                 # проверка типов во всех пакетах
npm run evaluate                  # офлайн-оценка рекомендаций → docs/evaluation-results.md
```

## Сквозная проверка в браузере

Сценарий выполнялся скриптом Playwright (Chromium, 1280×900) на запущенных API и клиенте:

1. Регистрация нового пользователя.
2. Онбординг: испанский, цель «Путешествия», 15 минут, входной тест.
3. Прохождение адаптивного входного теста: результат — уровень A1.
4. Переход по рекомендации «Что дальше» к уроку и прохождение урока со всеми типами заданий, включая пропуск произношения в headless-браузере.
5. Экран итогов: баллы, слабые темы, категории ошибок, слова в повторении, следующая рекомендация.
6. Возврат к плану на сегодня.

Ошибок JavaScript в консоли не было; ответы 401 при первоначальной проверке сессии ожидаемы. Сценарий выявил ошибку — плеер не сбрасывал состояние при переходе к следующему занятию. Ошибка исправлена, сценарий проходит.

Скриншоты всех основных экранов (главная, «Сегодня», путь, урок, плеер с обратной связью, повторение, словарь, прогресс, профиль, обзор и контент админ-панели) сняты в двух разрешениях — 1440×900 и 390×844 — и просмотрены вручную. По итогам исправлены: подписи без данных на графике тем, падежные формы в причинах рекомендаций, ширина кнопок на телефоне.

## Ручные проверки API

- `GET /api/health`, `/api/languages`, `/api/docs` на производственной сборке (`node dist/index.js`, `NODE_ENV=production`).
- Рекомендации и план демо-учащегося после генерации истории: слабая тема «Притяжательные формы» с причинами, тест модуля, повторение.

## Что не проверено

- Сборка Docker-образов в среде разработки упиралась в ограничение частоты запросов Docker Hub (HTTP 429). Состояние сборки на момент подготовки отчёта указано в README.
- Живой запрос к Wiktionary: внешний доступ из среды был закрыт. Проверены разбор ответа и обработка недоступности.
- Отправка писем через SMTP: проверена только ветка без настроенного SMTP.
- Синтез и распознавание речи на реальных устройствах. В headless Chromium голосов нет, поэтому проверены ветки недоступности.
- Автоматические проверки доступности (axe) и кроссбраузерное тестирование (Safari, Firefox) не выполнялись.
- Нагрузочное тестирование не выполнялось.
