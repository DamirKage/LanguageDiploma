# LinguaPath — персонализированная платформа для изучения языков

Веб-платформа для изучения **казахского, английского, турецкого, немецкого и испанского** языков на уровнях A1–C1 (CEFR). Интерфейс на русском языке. Платформа анализирует ответы учащегося, находит слабые темы, планирует занятия под доступное время, возвращает слова по алгоритму интервального повторения и объясняет причину каждой рекомендации.

Стек: React 19 + TypeScript + React Router + TanStack Query + Chart.js на клиенте; Node.js 24 + Express 5 + MongoDB (Mongoose) + JWT + bcrypt + zod + Swagger/OpenAPI на сервере. Монорепозиторий на npm workspaces.

## Возможности

- Регистрация, вход, выход, восстановление и смена пароля, профиль, удаление аккаунта.
- Роли «учащийся» и «администратор».
- Онбординг: язык → цели → время в день → адаптивный входной тест или выбор уровня.
- Программа курса: уровни → модули → уроки (105 уроков, по 21 на язык, A1–C1; уровень C1 добавлен сверх ТЗ по решению владельца) с целью, короткой теорией, ориентированной на русскоязычных, и словами урока с озвучкой.
- Озвучка всего курса нейросетевыми голосами: 5170 записей (слова, примеры, фразы теории, задания, тесты), диалоги — двумя голосами, повторное нажатие — медленнее; казахский — голоса ISSAI (Назарбаев Университет). Записи подготовлены заранее офлайн-моделями Piper (`tools/audio`), поэтому работают без ключей API и интернета. Режим «слушайте и повторяйте» — запись своего голоса для сравнения с образцом.
- 13 типов заданий: выбор, заполнение пропуска, перевод в обе стороны, порядок слов, диалог, аудирование, произношение и интерактивные «Найдите ошибку», «Текст с пропусками», «Переписка» (ролевой диалог в мессенджере, собеседник отвечает голосом) и «Разложите по группам» (перетаскивание или выбор), а также связный текст или аудиодиалог двумя голосами с вопросами (текст записи открывается после ответа) и письмо по заданию: проверяются объём и нужные конструкции, затем показываются образец ответа, перевод и пункты самопроверки. Произношение — экспериментальная функция на Web Speech API; если распознавание недоступно, предлагается письменная замена.
- Мгновенная обратная связь с объяснением. Ответ может быть засчитан как «почти верный»: диакритика, казахские буквы, опечатка. Ошибки учитываются в аналитике по теме и навыку и попадают в персональный план как практика слабой темы.
- Контрольные тесты после уроков (собственные вопросы, не повторяющие задания урока) и итоговые тесты модулей с отложенной обратной связью и разбором ответов.
- Персональные рекомендации с объяснением причин, план на день под бюджет времени, регулировка сложности.
- Интервальное повторение по упрощённому SM-2 с учётом часового пояса.
- Личный кабинет: языки и уровни, план и рекомендации, точность и время по дням, точность по темам с динамикой, ошибки по категориям и типам заданий, журнал ошибок, прогноз нагрузки повторения, трудные слова, история занятий.
- Панель администратора:
  - языки, уровни, модули, уроки с редактором заданий всех типов, публикация;
  - словарь с загрузкой аудио и изображений и справкой Wiktionary;
  - тесты, медиафайлы, список пользователей;
  - агрегированная статистика.
- Анимации со смыслом: слова подсвечиваются по мере произношения, визуализатор следует за реальным звуком, плитки перелетают в предложение, маркер едет по шкале уровня; отключаются системной настройкой «уменьшить движение».
- Темы оформления «Ночь», «День», «Бумага» и «Как в системе»; все проходят проверку контрастности WCAG AA.
- Документация REST API: Swagger UI на `/api/docs`, OpenAPI 3.1 на `/api/openapi.json`. Документ генерируется из тех же zod-схем, что валидируют запросы.

## Самый простой запуск

Нужен только Node.js 22.12 или новее (рекомендуется 24 LTS). База данных встроена и хранит данные в папке `demo-data`.

- Windows: `start-windows.bat`; macOS: `start-mac.command`; или `npm install && npm run demo`.
- Сайт открывается на http://localhost:8080. Подробная инструкция — в `START-HERE.txt`.

## Быстрый старт (локальная разработка)

Требуется Node.js ≥ 22.12 (рекомендуется 24 LTS) и MongoDB 8. Проще всего запустить MongoDB в Docker: `docker run -d -p 27017:27017 mongo:8`.

```bash
npm install
cp server/.env.example server/.env        # при необходимости отредактируйте
npm run seed -- --reset                   # учебный контент, администратор и демо-учащиеся
npm run dev --workspace server            # API: http://localhost:4000 (документация: /api/docs)
npm run dev --workspace client            # клиент: http://localhost:5173 (проксирует /api)
```

Демонстрационные аккаунты создаются скриптом `seed`:

| Роль | Почта | Пароль |
|---|---|---|
| Учащийся (немецкий, история за 3 недели) | `demo@linguapath.local` | `LinguaDemo2026` |
| Администратор | `admin@linguapath.local` | `LinguaAdmin2026` |

Пароли задаются переменными `SEED_ADMIN_PASSWORD` и `SEED_DEMO_PASSWORD`. Для публичного развёртывания их обязательно нужно сменить. Демо-учащиеся помечены `isDemo: true` и отделены от реальных пользователей.

## Запуск в Docker

```bash
cp .env.example .env
# впишите JWT_ACCESS_SECRET: node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
docker compose up -d --build
docker compose --profile seed run --rm seed
# приложение: http://localhost:8080
```

Состав: `mongo` (том `mongo-data`), `server` (Express, том `uploads`), `client` (nginx отдаёт сборку и проксирует `/api` и `/uploads`). При работе по HTTPS установите `COOKIE_SECURE=true`.

> Проверено 06.11.2026: `docker compose build`, `up`, заполнение базы (`--profile seed run --rm seed`), вход и раздача аудио через nginx работают с нуля; сервер в контейнере запускает по процессу на ядро (`WEB_CONCURRENCY=auto`).

### Развёртывание в облаке

Подходит любая платформа с поддержкой Docker Compose или контейнеров (VPS, Render, Railway, Fly.io) и управляемая MongoDB (например, MongoDB Atlas):

1. Задайте `MONGODB_URI`, `JWT_ACCESS_SECRET`, `PUBLIC_APP_URL`, `CLIENT_ORIGIN`, `COOKIE_SECURE=true`, `TRUST_PROXY=true` и при наличии SMTP — `SMTP_URL`.
2. Отдавайте клиент и API с одного домена (как в `client/nginx.conf`), чтобы refresh-cookie с `SameSite=Strict` работала без дополнительных настроек.
3. Один раз выполните `node dist/seed.js` в контейнере сервера.

## Переменные окружения сервера

См. `server/.env.example`. Основные: `MONGODB_URI`, `JWT_ACCESS_SECRET` (в продакшене обязателен, не короче 32 символов), `ACCESS_TOKEN_TTL_SEC`, `REFRESH_TOKEN_TTL_DAYS`, `BCRYPT_ROUNDS`, `CLIENT_ORIGIN`, `PUBLIC_APP_URL`, `SMTP_URL`, `EXPOSE_DEV_LINKS` (только для разработки, в продакшене запрещён), `RATE_LIMIT_ENABLED`, `UPLOAD_DIR`, `MAX_UPLOAD_MB`, `DICTIONARY_ENABLED`.

## Известные ограничения

- Учебный контент (45 уроков, 353 задания, 278 слов) написан для демонстрации и не проходил методическую экспертизу. Рекомендуется проверка носителями языка, особенно казахского и турецкого.
- Озвучка и распознавание речи зависят от браузера и установленных голосов. Казахский голос есть не во всех системах. Если голоса нет, интерфейс сообщает об этом и предлагает пропустить задание без штрафа. Администратор может загрузить собственные аудиозаписи.
- Задания аудирования передают текст для синтеза речи в браузер, поэтому технически подготовленный пользователь может увидеть ответ в сетевых запросах. Для учебной платформы без экзаменов это приемлемо.
- Рекомендательный движок основан на правилах с ручными весами. В симуляции он заметно лучше последовательной стратегии, но по покрытию слабых тем уступает случайному выбору из того же пула кандидатов (см. `docs/recommendation-algorithm.md`). Данные для обучения модели уже собираются.
- Справка Wiktionary даёт определения на английском. Живой запрос к сервису из среды разработки не проверялся.
- Интерфейс поддерживает одну локаль (русский). Архитектура готова к добавлению других.
